# Carousel açıklaması (2. gönderi)

Garsonunuz yabancı dil bilmiyorsa, turist masası sizi bırakıp gidebilir.

Turist masalarında sorun menü değil, dildir. Garson el kol hareketiyle uğraşırken bekleyen masalar kaybedilir, yanlış anlaşılan sipariş düşük puana dönüşür.

Çoklu Dil modülüyle:
✔ Menü 20'den fazla dilde
✔ Turist siparişini kendi dilinde verir
✔ Garsonunuz dil bilmek zorunda değil

Sonuçlar 4. slaytta. Kaydırın 👉

Canlı menüyü görmek için profildeki bağlantıya tıklayın.
Turistli bölgede restoranı olan birine gönderin.
