# QR Menu Official — Ana Site

QR Menu Official'ın ana satış sitesi için çalışma alanı.

## Yapı

- `index.html` — Ana sayfa (henüz kodlanmadı)
- `DESIGN_SYSTEM.md` — Tasarım sistemi dokümantasyonu (henüz doldurulmadı)
- `CONTENT_STRATEGY.md` — İçerik stratejisi dokümantasyonu (henüz doldurulmadı)
- `paketler/` — `/paketler/` fiyat sayfası (içerik: `paketler/packages-data.js`)
- `moduller/` — `/moduller/` modül dizini + 10 modül sayfası (içerik: `moduller/module-data.js`; üretim: `node moduller/build.js`)
- `sitemap-paketler-moduller.xml` — `build.js` çıktısı; mevcut sitemap/robots ile birleştirme dağıtım tarafının işidir
- `sections/` — Sayfa bölümleri
- `css/` — Stil dosyaları
- `js/` — JavaScript dosyaları
- `assets/` — Görsel ve statik dosyalar
